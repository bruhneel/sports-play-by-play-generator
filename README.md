# Sports Play-by-Play Generator

[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/qrqptsmr28/badge.svg)](https://ask.thili.ai/b/qrqptsmr28)

This project creates a command-line assistant that generates dynamic sports commentary. It applies the principles of GPT from scratch, training on sports news to produce contextually relevant play-by-play snippets for fictional game scenarios.

## What you are building

**Goal.** You will have built a command-line assistant that generates short, dynamic commentary snippets for fictional game scenarios, trained on real sports news articles.

**Done when.** The project is done when a command-line interface allows users to input a prompt and receive short, dynamic sports commentary snippets generated by a custom-trained GPT model.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
python -m app.cli hello
pytest
```

Your work goes in `app/core.py` (one stub per milestone) and `tests/test_core.py`. The first tests pass already; they
check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever
reaches GitHub, treat it as leaked and make a new one.
